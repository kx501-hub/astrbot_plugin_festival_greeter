# Festival Greeter 节日与生日祝福插件

一个面向 AstrBot 的节日祝福插件，在指定节日自动调用 LLM 生成问候语并推送到目标会话，支持群黑白名单、生日私聊、兜底文案与手动触发。默认内置中国节日（含部分传统农历节日映射），可按需扩展。

## 功能概览
- 预置以中国法定与传统节日为主的节日集合，支持自定义扩展。
- 自动在配置时间调用 LLM 生成人格设定的祝福，并推送到目标群聊或生日私聊。
- 可从 AstrBot 已配置的人格中选择祝福使用的人格及预设对话，定时推送和手动触发保持一致。
- 白名单／黑名单两种群发送模式，默认使用白名单。
- 支持多条兜底模板，在 LLM 不可用时保持服务。
- 提供 `/festival-send` 指令手动触发节日祝福（可配置开关）。
- 持久化记录推送历史，避免同一节日在冷却时间内重复发送。
- 支持节日持续天数配置，可选择仅首日推送或节期内每日推送。
- 支持群聊或私聊生日祝福，每条生日独立选择公历或农历，并填写对象及附加信息。

## Pages 管理页面

在 AstrBot WebUI → 插件 → 节日与生日祝福 → Pages → **祝福管理** 打开。需要支持 Plugin Pages 和 `astrbot.api.web` 的 AstrBot 版本，首次增加页面后请重载插件。

- 可视化编辑生日、公历自定义节日、持续天数、别名和附加信息；保存到原插件配置，后续调度立即使用新日历。
- 时区、发送时间、人格、模型及群名单继续在插件基础配置中设置。
- 预览当前草稿未来 30 / 90 / 366 天的安排、目标会话和输入提示词。预览不调用模型、不发消息、不登记群；实际发送还会检查去重记录。只预览不会保存草稿。
- 查看最近 200 条成功发送记录。旧记录没有祝福正文，页面展示群、时间和内部标识。
- 旧的“日期＋名称”自定义节日配置可直接读取；简单条目保持原格式，设置持续天数、别名或说明后使用插件原本支持的对象格式，此时建议在 Pages 中编辑。
- 保存时检测其他页面的配置修改；发生冲突需重新载入。页面无独立端口或密码，也不依赖前端构建工具。

中文节日现在按名称覆盖内置定义，并使用不同的去重标识，避免多个中文节日互相覆盖或阻止发送。兼容旧 `holiday-日期` 发送记录：该日期已有旧记录时仍抑制重复发送；旧记录无法区分具体节日。

## 配置说明（_conf_schema.json）
- `timezone`：IANA 时区标识，默认 `Asia/Shanghai`。
- `trigger_time`：每日调度时间，24 小时制 `HH:MM`。
- `group_filter_mode`：`whitelist` / `blacklist`。默认 `whitelist`；白名单中的群就是发送目标，黑名单模式向可发现的全部群发送并排除名单内群。
- `group_filter_list`：白名单模式下填写发送目标，黑名单模式下填写禁止发送的群。推荐使用完整统一会话 ID，也可只填 aiocqhttp 群号。
- `llm_provider_id`：可选，指定用于祝福生成的 LLM Provider ID；留空使用目标会话的默认模型。
- `persona_id`：通过人格选择器选择 AstrBot 已配置的人格，所有目标群统一使用所选人格；初始值为 `default`（AstrBot 内置默认人格）。
- `custom_holidays`：一条配置对应一个节日，可填写公历开始日期、持续天数、别名、说明和可选的目标群会话 ID。
- `birthdays`：在“生日祝福”中添加条目，填写必需的成员 ID、发送方式、历法、月和日。群聊还需完整群会话 ID，私聊还需平台实例 ID；称呼、备注及其他附加信息均可留空。
- `fallback_messages`：兜底祝福模板，支持 `{holiday}`、`{date}`、`{year}` 占位符。
- `max_generation_retries`：LLM 调用失败时的额外重试次数。
- `allow_manual_trigger`：是否允许 `/festival-send` 指令。
- `holiday_repeat_mode`：节日推送策略，`first-day` 仅首日推送，`every-day` 节期内每日推送。

示例 `custom_holidays` 配置：

```json
{
  "name": "周年庆",
  "target_session": "bot:GroupMessage:123456",
  "month": 12,
  "day": 30,
  "length_days": 3,
  "aliases": ["纪念日"],
  "description": "群成立周年"
}
```

这个例子从每年 12 月 30 日开始，持续 3 天并跨到次年 1 月 1 日，只向绑定群发送。目标群留空时，使用白名单中的目标，或黑名单模式下可发现的全部群。旧版“日期＋名称”列表会在插件载入时自动迁移为逐条配置。

白名单模式最直接：例如名单中填写 `bot_instance:GroupMessage:123456`，内置节日和未单独绑定群的自定义节日都会直接发到该群，无需执行登记指令。生日或自定义节日显式绑定的群也必须在白名单内。

黑名单模式会排除名单内群，并向机器人可发现的其他群发送。OneBot/NapCat 会主动读取机器人群列表；其他平台缺少统一的群枚举接口，插件会自动记住收到过消息的群，不需要执行登记命令。刚安装后从未产生过消息的非 OneBot 群，要等该群出现一条消息后才能被发现。

在插件配置中点击“祝福人格”，选择已有的 AstrBot 人格并保存。定时推送、手动发送和调试指令均使用此人格，不受群聊当前人格影响。旧版 `llm_prompt_style` 配置不再生效。所选人格被删除、读取失败或模型调用失败时，使用固定兜底文案。

传给人格的信息格式如下；字数、语气和表达方式由所选人格决定：

```text
祝福类型：节日
对象：全群
附加信息：节日名：中秋节；日期：2026-09-25；节日别名：仲秋节；目标群 ID: 123456
```

## 生日祝福

在插件配置的“生日祝福”中新增生日，例如：

- 成员 ID：`123456789`
- 称呼／备注：小明（可选）
- 发送方式：`group`（群聊）或 `private`（私聊）
- 目标群会话 ID：`qq_bot:GroupMessage:123456`（替换为实际平台实例 ID 和群号）
- 平台实例 ID：`qq_bot`（仅私聊填写，替换为实际平台实例 ID）
- 历法：`solar`（公历）或 `lunar`（农历）
- 月、日：分别填写数字，例如 `8`、`15`
- 附加信息：`老朋友，喜欢摄影，希望语气亲切`

生日在配置时区的每日 `trigger_time` 发送到指定群或成员私聊。群聊受群白名单或黑名单约束；私聊使用平台实例 ID 和成员 ID 直接定位，不受群名单影响。使用所选人格，传入格式如下：

```text
祝福类型：生日
对象：对应成员
附加信息：日期：2026-09-25；生日：农历8月15日；称呼：小明；老朋友，喜欢摄影，希望语气亲切；目标群 ID: 123456
```

成员 ID 是生日条目的唯一成员标识，QQ 平台填写 QQ 号，其他平台填写相应的用户 ID。称呼／备注可选，填写后作为附加信息传给人格；未填写时提示词使用“对象：对应成员”，不会把成员 ID 交给人格。群聊开启“@ 寿星”后，定时推送、`/festival-send` 和 `/festival-debug` 会在正文前 @ 对应成员，且不会 @ 全体成员。私聊始终忽略 @ 配置。不同成员的生日分别记录，避免互相影响。

私聊条目只填写平台实例 ID 的第一段，例如统一会话 ID `bot_instance:GroupMessage:123456` 对应的平台实例 ID 是 `bot_instance`。插件会自动组成 `bot_instance:FriendMessage:成员ID` 作为私聊目标。

公历 2 月 29 日只在闰年发送；农历按实际月日匹配，某年没有该日则不发送。普通农历月不会在同名闰月重复发送；开启“农历闰月生日”后，仅在对应闰月发送，没有该闰月的年份不发送。农历换算依赖 [lunardate](https://pypi.org/project/lunardate/)，支持农历 1900–2099 年；更新插件时需安装 `requirements.txt` 中的依赖。

## 使用建议
1. **目标群**：白名单模式直接把名单作为发送目标；黑名单模式发送到可发现的群并排除名单项，不再需要执行 `/festival-send` 登记。
2. **名单应用**：
   - 白名单：名单中的群就是发送目标，显式绑定群也必须在名单内。
   - 黑名单：名单内会话被排除，其余已发现群均可推送。
3. **兜底模板**：至少预置 1 条 `fallback_messages`，保障在 LLM 服务不可用时仍能发送祝福。
4. **数据存储**：推送记录保存在 `data/festival_greeter/deliveries.json`，自动定期清理。
5. **Napcat / QQ 适配**：请确认机器人具备对目标群的主动发言权限。
6. **自定义节日**：每条独立配置开始日期和持续天数。`first-day` 仅开始当天推送，`every-day` 会在整段日期内每天推送。

## 指令说明
- `/festival-send`：在当前会话手动发送当日节日祝福，不再承担登记功能。若当天节日已推送或会话被名单限制，将返回提示。
- `/festival-debug`：管理员专用调试指令，忽略冷却直接向当前会话推送当日节日祝福，可用于验证配置与 LLM 调用。

## 开发要点
- 遵循 AstrBot 插件的 `@register` 注册与 `Star` 生命周期约定。
- 调度任务通过 `asyncio.create_task` 启动，`terminate` 中会安全取消。
- LLM 响应通过 `extract_text_from_response` 做格式化处理，兼容多种 Provider 返回结构。
- 群推送调用 `context.send_message(unified_msg_origin, MessageChain)`，可兼容 Napcat。

## 常见问题
- **为何没有发送祝福？**
  - 确认群不在黑名单，或白名单模式下已经加入名单。
  - 查看 `data/festival_greeter/deliveries.json` 是否已记录当日发送。
- **如何新增推送群聊？**
  - 白名单模式：把完整群会话 ID 加入群名单。
  - 黑名单模式：OneBot/NapCat 自动读取全部群；其他平台在群内出现消息后自动发现。
- **LLM 未生成文本**：日志会输出错误原因，插件自动使用兜底模板。可调大重试次数或更换 Provider。
- **节日日期不正确**：内置节日包含部分农历节日，对 2024-2030 年进行了阳历映射；可在 `custom_holidays` 中覆盖或追加。
