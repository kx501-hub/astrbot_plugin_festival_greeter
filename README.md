# 节日与生日祝福

插件会在设定时间为节日或生日生成祝福，并发送到指定群聊或生日对象的私聊。祝福由你选择的 AstrBot 人格生成，也可以配置备用文案。

## 开始使用

在 AstrBot 的插件配置中设置：

- **祝福人格**：选择已配置的人格。
- **发送时间与时区**：设置每日检查祝福的时间和所用时区。
- **群发送模式**：选择白名单或黑名单，并填写群名单。白名单中的群会收到祝福；黑名单中的群不会收到祝福。
- **生成模型**：可选指定祝福使用的模型；留空时使用目标会话对应的模型。

白名单是默认模式。群名单填写群号或完整群会话 ID。生日或自定义节日绑定了群聊时，该群也必须通过群名单检查。私聊生日不受群名单影响。

## 管理节日和生日

在 AstrBot → 插件 → 节日与生日祝福 → Pages → **祝福管理**打开管理页面。可以添加生日和自定义节日、预览安排与提示词，并查看近期发送记录。修改完成后点击“保存更改”。

### 生日祝福

每位寿星添加一条生日，填写：

- **发送方式**：群聊或私聊。
- **接收目标**：群聊填写完整群会话 ID；私聊填写平台实例 ID。私聊目标由平台实例 ID 和成员 ID 组成。
- **成员 ID**：必填。用于确定接收对象；QQ 填 QQ 号，其他平台填相应用户 ID。
- **称呼／备注**：可选，会作为附加信息交给人格。未填写时，人格会收到“对象：对应成员”，不会收到成员 ID。
- **生日历法和日期**：选择公历或农历，再填写月份和日期。农历生日可选择是否仅在闰月发送。
- **@ 寿星**：群聊可选。私聊会忽略此设置。
- **附加信息**：可选，可填写对方特点、兴趣或你们的关系。

生日按配置的时区和每日发送时间推送。公历 2 月 29 日只会在闰年发送；农历日期不存在的年份不会发送。农历换算支持 1900–2099 年。

### 自定义节日

每条自定义节日填写名称、公历开始日期和持续天数，也可填写别名、说明及目标群。目标群留空时，按当前群发送模式选择目标。节日名称与内置节日相同时，会使用自定义设置。

持续天数大于 1 时，可在插件配置中选择只在首日发送，或在节期内每天发送。

## 发送指令

两条指令仅机器人管理员可用。

- `/festival-send`：向当前会话发送当天祝福。也可指定完整会话 ID，例如 `/festival-send 平台实例:GroupMessage:群号`。此指令绕过插件的群名单限制，但当天已成功发送的祝福不会重复发送。是否启用此指令由插件配置控制。
- `/festival-debug`：向当前会话发送当天祝福，不检查当天发送记录，便于确认配置和生成效果。

生日群聊会按条目设置选择是否 @ 寿星；私聊生日不会 @。发送记录用于避免重复祝福。

## 备用文案

可添加一条或多条备用祝福。人格或模型无法生成内容时，插件会随机选用备用文案；未配置时使用插件内置文案。备用文案支持 `{holiday}`、`{date}` 和 `{year}`，分别表示节日或生日名称、日期和年份。
